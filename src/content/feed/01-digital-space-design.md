这个站最先写好的不是页面，是一份设计系统。原因很实际：没有视觉稿、没有设计师，如果每次改样式都靠「感觉好不好看」，二十几个版本之后一定散架。把审美翻译成硬约束，后面每一次改动才有判据。

## 先把颜色砍到最少

最后只留下三档白、两级墨，加一组环境光：

```css
--color-space-0: #f7f5fc;   /* 页面底 */
--color-space-1: #fafbfe;   /* 浮起的面 */
--color-space-2: #f3eef8;   /* 更深一档的底 */
--color-ink:     #1d1d22;   /* 正文 */
--color-ink-2:   #5e5e6b;   /* 次级 */
--color-ink-3:   #6f6f7d;   /* 眉标、日期、注释 */
```

颜色少的好处不是"素"，是**每一个颜色都有职责**。正文永远是 ink，辅助信息永远是 ink-2/3，不存在"这个灰看着舒服就用这个灰"。后来做夜航模式，也只是把这几个变量换一套值，组件一行没改。

## 粉紫只准待在一个地方

这条规矩救了这个站：**粉紫色只能出现在环境光层**，按钮、链接、标签、色块里出现粉紫一律算违规。

原因是我见过太多"二次元个人站"死在这个地方——粉紫一旦进入交互元素，整页就会迅速变成糖果色，再怎么调都救不回来。把它限制在背景光晕里，页面主体就能保持冷白，情绪由光来给，而不是由色块来给。

## 光只有一个方向

全站唯一光源在右上角，所有高光在元素右上，所有投影落向左下。听起来很玄，落到 CSS 里就是两条：

- 玻璃面板的高光边只在 `inset -1px 1px 0`；
- 阴影统一 `box-shadow: 12px 18px 40px rgba(...)`，不允许向左上。

方向统一之后，页面里所有元素才像"在同一个空间里"，而不是一堆贴纸。

## 线代替框

整个站没有卡片、没有外框、没有厚阴影。分隔靠 1px 的发丝线：

```css
--color-hair: rgba(29, 29, 34, 0.16);
--hair-frame: rgba(29, 29, 34, 0.28);
```

发丝线的好处是"存在但不抢戏"。同样的内容，加了圆角卡片会立刻变成后台管理界面；换成一条 1px 线，阅读节奏还在，视觉重量却几乎为零。

## 写进 CSS，而不是写进脑子

设计系统最后落成一个 `global.css`：颜色、间距、圆角、缓动全在 `@theme` 里，组件只消费变量。这条执行得并不轻松——早期图省事硬编码了五十多处颜色，后来整批返工清了一遍，非常痛苦。

踩过最阴的一个坑是 Astro 的 scoped style：组件里写 `[data-theme='night'] .foo` 会被自动加上 `data-astro-cid`，永远匹配不到 `<html>` 上的属性，表现是"夜航值不生效，重启也没用"。解法是 `:global([data-theme='night']) .foo`。这种坑不写下来，下次还会踩。

## 结果

这套约束撑住了后面二十多个版本的迭代：换页脚、换播放器、加备案、改配色，都能在一个下午内完成，而且不会把别的地方带崩。设计系统真正的作用不是"好看"，是**让改动可预测**。
